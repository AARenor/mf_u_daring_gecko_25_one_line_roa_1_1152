# One-line gadget roast

A program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a single original line roasting the gadget I use every day, written to `entry.txt` with no trailing newline, printed character count on stderr, and an assertion that the text stays between 1 and 280 characters.
